# Content Improvement Plan for Georgia Expat Site

## Executive Summary
After auditing the site content, I've identified key areas for improvement to enhance user value, SEO, and engagement. This plan focuses on making content more actionable, accurate, and comprehensive.

---

## 🎯 Priority 1: Critical Content Gaps

### 1. Missing Real Data & Specifics
**Current Issue:** Many pages have placeholder or generic content
**Impact:** Users can't make informed decisions

**Actions Needed:**
- **Restaurants Page:** Add 15+ more real restaurants with actual addresses, phone numbers, and current prices
- **Housing Page:** Only 4 neighborhoods listed - expand to 10+ with real rental prices from ss.ge
- **Language Page:** 20 lessons is good, but needs actual audio/video links (currently placeholders)
- **All Pages:** Replace "coming soon" and placeholder content with real information

### 2. Outdated Information
**Current Issue:** Some content references 2026 as future, but we're in 2025
**Impact:** Confuses users about timeline

**Actions Needed:**
- Update all "Moving to Tbilisi in 2026" references to "2025-2026"
- Add "Last Updated: [Date]" to all major content pages
- Create update schedule for time-sensitive content (prices, visa rules, etc.)

### 3. Missing Practical Details
**Current Issue:** Content is informative but lacks actionable specifics
**Impact:** Users still need to research elsewhere

**Actions Needed:**
- Add exact addresses with Google Maps links
- Include actual phone numbers and websites
- Add operating hours for all businesses
- Include real prices in GEL (not just ranges)
- Add public transport directions to key locations

## 🎨 Priority 4: Content Organization

### Current Issues:
- Too much content on homepage (717 lines!)
- Some pages are too short (Housing: ~200 lines)
- Inconsistent structure across pages
- No clear content hierarchy

### Improvements:
1. **Homepage:** Reduce to 400 lines, move detailed content to subpages
2. **Create new subpages:**
   - `/housing/neighborhoods` - Detailed neighborhood guide
   - `/restaurants/budget` - Budget eating guide
   - `/restaurants/fine-dining` - Upscale dining
   - `/language/alphabet` - Georgian alphabet deep dive
   - `/moving/timeline` - Interactive moving timeline
   - `/expat-stories` - Real expat experiences

3. **Standardize page structure:**
   ```
   - Hero section with key info
   - Quick stats/overview
   - Main content sections
   - Practical tips sidebar
   - Related resources
   - Last updated date
   ```

## 📊 Priority 7: SEO & Discoverability

### Current Issues:
- Good metadata on some pages, missing on others
- No blog post structure for SEO
- Missing schema markup
- No internal linking strategy

### Improvements:
1. **Add to all pages:**
   - Proper meta descriptions
   - Open Graph tags
   - Schema markup (Article, LocalBusiness, etc.)
   - Canonical URLs
   - Alt text for all images

2. **Content SEO:**
   - Add FAQ schema to FAQ page
   - Add LocalBusiness schema to restaurant listings
   - Create pillar content strategy
   - Internal linking between related pages
   - Add "Related Articles" sections

3. **Blog Strategy:**
   - Convert some guides into blog posts
   - Add author bios
   - Add publish dates
   - Create content calendar
   - Target long-tail keywords
